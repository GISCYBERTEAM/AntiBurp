# AntiBurp
<img width="1699" height="1099" alt="image" src="https://github.com/user-attachments/assets/7e96dbfc-b86d-4a78-b274-3e0582aa253b" />

Платформа для тестирования безопасности веб-приложений. Инструмент для ручного и автоматизированного анализа HTTP/HTTPS-трафика, поиска уязвимостей и проверки защищённости веб-приложений.
# Основные возможности
## Прокси-сервер
- Перехват и анализ HTTP/HTTPS-трафика в реальном времени
- MITM для HTTPS с поддержкой TLS
- Настраиваемые слушатели (listeners) на разных портах
- Поддержка upstream-прокси (HTTP и SOCKS5)
- История запросов с фильтрацией и поиском
## Перехватчик (Interceptor)
- Пауза и модификация запросов и ответов перед отправкой
- Режим включения/выключения для выборочного перехвата
- Удобный интерфейс для принятия решений по каждому запросу
## Повторитель (Repeater)
- Повторная отправка запросов с изменениями
- Несколько вкладок для параллельной работы
- История запросов и ответов
- Режимы просмотра: Pretty, Raw, HEX
## Автоматизатор (Intruder)
- Автоматизированные атаки по аналогии с Burp Intruder
- Типы атак: Sniper, Battering Ram, Pitchfork, Cluster Bomb
- Позиции с типами «Числа» и «Словарь»
- Настройка частоты запросов, задержек и разброса
- Отображение количества запросов для каждой позиции
## Цели (Targets)
- Дерево доменов и путей по перехваченному трафику
- Фильтрация запросов по хосту и пути
- Сортировка и поиск по запросам и ответам
- Обработка заголовков
## Модули
- Модуль для добавления, замены и удаления HTTP-заголовков
- Правила применяются ко всем исходящим запросам
# Организация работы
## Общая информация
- Проекты — отдельные рабочие пространства для разных задач
- Многопользовательский режим — роли, доступы и права
- Экспорт и импорт — сохранение и перенос данных между проектами
## Запуск
### Linux / macOS
```bash
./antiburp
```
### Windows
```cmd
antiburp.exe
```
## Доступ к интерфейсу
После запуска откройте в браузере:
**http://localhost:13444**
Учётные данные по умолчанию (если не менялись):
- **Логин:** admin
- **Пароль:** admin123
## Настройка прокси в браузере
1. Откройте AntiBurp и создайте проект
2. В разделе **Настройки** проекта укажите адрес и порт (например, `127.0.0.1:8080`) и нажмите **Создать слушатель** 
3. Настройте браузер на использование прокси:
   - **Chrome:** Настройки → Система → Открыть настройки прокси → Ручная настройка
   - **Firefox:** Настройки → Основные → Параметры сети → Настроить
   - **Edge:** Аналогично Chrome

4. Для HTTPS с перехватом (MITM) установите корневой сертификат CA: в AntiBurp перейдите в **Настройки проекта** → **Сертификат CA** → **Скачать** и установите в доверенные корневые центры сертификации.
