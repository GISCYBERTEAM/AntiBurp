Установка CA сертификата

Скачайте сертификат и установите его в доверенные, чтобы браузер доверял HTTPS перехвату.

macOS

  1. Откройте «Связка ключей».
  2. Импортируйте файл `antiburp-ca.pem` в «Системные».
  3. Откройте сертификат, установите «Всегда доверять».
  4. Перезапустите браузер.

Windows

  1. Запустите `certmgr.msc`.
  2. «Доверенные корневые центры сертификации» → «Сертификаты».
  3. Импортируйте `antiburp-ca.pem`.
  4. Перезапустите браузер.

Linux (Ubuntu/Debian)

  1. Скопируйте файл в `/usr/local/share/ca-certificates/antiburp-ca.crt`.
  2. Выполните `sudo update-ca-certificates`.
  3. Перезапустите браузер.
Для сайтов с HSTS/Certificate Pinning перехват HTTPS может быть невозможен.
