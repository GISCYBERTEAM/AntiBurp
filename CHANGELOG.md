# Changelog

## [1.2.0] — 2026-03-15

### Контекстные меню

- **Цели** — контекстное меню для Запроса и Ответа: «Отправить в повторитель», «Отправить в автоматизатор», «Копировать»

- **Ответ** — вкладки Pretty, Raw, HEX, Render для режима просмотра ответа

## [1.1.0] — 2026-03-12

### Интерфейс и отображение

- **Единый layout панелей** — блоки «Запрос» и «Ответ» с фиксированной высотой 374px и прокруткой на страницах Цели, Прокси, Повторитель, Перехватчик, Автоматизатор
- **История Повторителя** — фиксированная высота 374px с прокруткой
- **Read-only Pretty** — в режиме Pretty без overlay для корректного выделения текста на страницах: Цели (Запрос, Ответ), Прокси (Запрос, Ответ), Повторитель (Ответ), Процесс отправки (Запрос, Ответ)
- **Editable Pretty** — overlay с возможностью редактирования для: Перехватчик (Запрос), Повторитель (Запрос), Автоматизатор (Запрос)
- **Синхронизация editable overlay** — прокрутка на родительском контейнере (code-scroll), pre и textarea двигаются вместе; выделение и копирование совпадают с текстом
- **Совпадение переноса строк** — одинаковый `overflow-wrap: break-word` для pre и textarea
- **Совпадение содержимого** — в подсветке используются сырые значения параметров (escapeHtml вместо decodeURIComponent) для корректной синхронизации на длинных query и cookie

### Тема оформления

- **Светлая тема по умолчанию** — при первом запуске используется светлая цветовая схема
- **Сохранение настроек темы** — выбранная тема сохраняется в localStorage и применяется при следующих загрузках
- **Тумблер в тёмной теме** — переменная `--slider-thumb` для видимости переключателя «Режим перехвата»

### Процесс отправки (модальное окно)

- **Названия колонок** — вместо «Нагрузка 1», «Нагрузка 2» отображаются имена позиций из шаблона запроса (текст внутри маркеров §...§)
- **Подсветка при выборе записи** — при клике по строке в списке запрос и ответ отображаются с цветовой подсветкой (Pretty)

## [1.0.0] — 2026-03-10

Первый стабильный релиз AntiBurp — инструмента для тестирования безопасности веб-приложений.

---

### Прокси

- **HTTP/HTTPS-прокси** — перехват и анализ трафика в реальном времени
- **MITM для HTTPS** — расшифровка TLS с динамической генерацией сертификатов
- **Несколько слушателей** — запуск прокси на разных адресах и портах
- **Upstream-прокси** — поддержка HTTP и SOCKS5 для выхода в интернет
- **История запросов** — до 500 записей с сортировкой по URL, статусу, времени, длине, MIME, серверу
- **Отображение метода** — в колонке «Запрос» показывается метод (GET, POST, CONNECT и т.д.)
- **Пул соединений** — до 150 соединений к upstream-прокси, семафор на 120 одновременных подключений
- **Таймаут простоя** — закрытие неиспользуемых соединений через 2 секунды

---

### Перехватчик (Interceptor)

- **Пауза трафика** — остановка запросов до принятия решения
- **Модификация** — изменение запроса перед отправкой
- **Разрешить/Отклонить** — управление каждым перехваченным запросом

---

### Повторитель (Repeater)

- **Повторная отправка** — отправка запросов с изменениями
- **Вкладки** — несколько вкладок для параллельной работы
- **История** — сохранение запросов и ответов
- **Режимы просмотра** — Pretty, Raw, HEX для запроса и ответа
- **Поиск** — в запросе, ответе или в обоих
- **Отмена** — прерывание долгих запросов

---

### Автоматизатор (Automator)

- **Типы атак** — Sniper, Battering Ram, Pitchfork, Cluster Bomb
- **Позиции** — маркеры `§значение§` в теле запроса
- **Типы payload** — Числа (от/до/шаг) и Словарь (список строк)
- **Количество запросов** — отображение для каждой позиции в реальном времени
- **Настройки** — пакетов в секунду, задержка, разброс
- **Вкладки** — несколько конфигураций
- **История запусков** — просмотр результатов, статусов, ответов
- **Модальное окно** — детальный просмотр запросов/ответов во время выполнения

---

### Цели (Targets)

- **Дерево доменов** — иерархия хостов и путей по перехваченному трафику
- **Обращения** — список запросов с фильтрацией по выбранному пути
- **Поддержка директорий** — пути с завершающим `/` отображаются как папки
- **Сортировка** — по URL, статусу, времени, длине
- **Поиск** — в запросе и ответе
- **До 2000 записей** — синхронизация дерева и списка обращений

---

### Модули и настройки

- **Обработка заголовков** — добавление, замена, удаление HTTP-заголовков
- **Кодировки** — настройка кодировки запроса и ответа
- **Сертификат CA** — скачивание и инструкция по установке для MITM
- **Экспорт/импорт** — перенос данных проекта
- **Очистка** — удаление всех данных проекта

---

### Проекты и пользователи

- **Проекты** — изолированные рабочие пространства
- **Список доступа** — приглашение пользователей в проект
- **Многопользовательский режим** — роли admin, moderator, user
- **Админ-панель** — управление пользователями, ролями, паролями
